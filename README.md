# Nova Plugins

Jacque's Revenge plugins, installable as a repository.

Add this repository URL in Revenge (Settings → Revenge → Plugins → gear → **Add repository by URL**):

```
https://raw.githubusercontent.com/ghostixs/nova-plugins/main/index.json
```

## Plugins

- **Usage Tracker** — DeepSeek $ and Codex % usage, pinned at the top of your channel list.
- **Notification List** — see every channel with unread messages and tap to jump straight to it.
- **DeepSeek Balance** — show your DeepSeek API credit balance in settings.
